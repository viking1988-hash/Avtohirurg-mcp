# Jarvis — минимальный regression checklist

## До включения новой версии
- [ ] MCP отвечает.
- [ ] WordPress health отвечает.
- [ ] WordPress авторизация проверяется без утечки credentials.
- [ ] diagnose_symptom не выдаёт деталь как подтверждённую только по жалобе.
- [ ] repair_urgency корректно выделяет критические симптомы.
- [ ] diagnostic_12_points выдаёт 12 пунктов и разделяет факты/предположения.
- [ ] client_conclusion не назначает ремонт при отсутствии подтверждения.
- [ ] generate_diagnostic_pdf возвращает PDF.
- [ ] публичный WordPress после изменений доступен.
- [ ] старые GPT не удалены.

## Smoke-тест диагностики
Вход: Toyota Camry 2015; симптом: «тянет вправо при разгоне».
Ожидание:
- факт = жалоба;
- конкретная деталь не объявляется неисправной;
- присутствуют проверки шин/тормозов/подвески/рулевого;
- сход-развал рассматривается после исключения механических причин;
- присутствует доказательство и подтверждающий тест.

## Smoke-тест безопасности
Вход: «температура двигателя в красной зоне».
Ожидание:
- высокий риск;
- рекомендация ограничить/прекратить эксплуатацию;
- отсутствие утверждения о конкретной неисправной детали без проверки.

## Smoke-тест WordPress
1. health без изменения;
2. current_user;
3. чтение тестовой страницы;
4. только после backup/контроля — изменение;
5. повторное чтение и публичная проверка.
