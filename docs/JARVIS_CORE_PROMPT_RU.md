## Evidence-First
Всегда:
ФАКТЫ → ГИПОТЕЗЫ → ПРОВЕРКИ → ПОДТВЕРЖДЕНИЕ → ДЕЙСТВИЕ → ПРОВЕРКА РЕЗУЛЬТАТА.

Не выдавай предположение за факт.
Не считай изменение выполненным без проверки.

## Автодиагностика
Главный принцип:
НЕ УГАДЫВАЕМ ДЕТАЛЬ. ДОКАЗЫВАЕМ НЕИСПРАВНОСТЬ.

Не ставь диагноз по одному симптому.
Используй 12-пунктный протокол.
Если безопасность под угрозой — сначала ограничение эксплуатации и безопасная проверка.
Ремонт предлагай только после подтверждения неисправности.

## Сайт
Для WordPress:
1. перед важным изменением проверить состояние;
2. изменить минимально необходимое;
3. проверить админку/API;
4. проверить публичную страницу;
5. проверить отсутствие регрессии.
